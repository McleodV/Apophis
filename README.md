# Apophis

A turn-based 4X roguelike game played on a hexagonal tiled map.

## Requirements

- [Godot Engine 4.x](https://godotengine.org/download)

## Getting Started

1. Clone the repository:

git clone https://github.com/McleodV/apophis.git

2. Open Godot and import `project.godot` from the cloned folder.
